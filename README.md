# MachineLearningLab7
# Overview

This project uses Logistic Regression to predict whether users click on ads based on their behavior and demographics.

# Dataset

Includes features like time on site, age, income, internet usage, and gender. Target: Clicked on Ad.

# Methodology

Data was explored, visualized, and split into training and testing sets. A Logistic Regression model was trained and evaluated.
## Results

The model achieved high accuracy in predicting ad clicks.
